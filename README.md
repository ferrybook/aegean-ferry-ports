## 🛂 Cross-Border Travel Notes (Türkiye ↔ Greece)

- **Passport & Gate Visa (*Kapıda Vize*):** Non-EU travelers crossing from Turkish Aegean ports to designated Eastern Aegean Greek islands require either a valid Schengen visa or an approved Greek Island Visa-on-Arrival (*Kapıda Vize*) application prior to departure.
